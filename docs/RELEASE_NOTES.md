# 1.0.0 首个公开版本

日期：2026-11-06。

- 基于飞牛原版资源管理改进，新增资源历史曲线与硬件温度曲线。
- 内置温度采集器、SQLite 存储和备份。
- 新增 service.py 统一管理资源与温度两个子进程，随 Pro 一起启动和停止。
- 温度数据库与备份位于 Pro var/temperature 子目录，资源数据库保持原位置。
- 本机端口使用 127.0.0.1:39188，仅通过已认证的 Pro CGI 暴露只读接口。

源码与发行包不携带历史数据、运行日志、硬盘序列号、密码或 fnOS 官方前端。
设备别名与官方图标仍通过被 Git 忽略的本机配置显式加入 local 构建。

项目许可证仍待作者确定。公开发布前需验证目标 fnOS 的干净安装与升级路径。
